# Changelog

## Unreleased

First working version. All 13 commands ported from the Bash implementation, driven live
against a real herdr daemon and real agents.

### Commands

`up`, `chat`, `ask`, `tidy`, `brainstorm`, `plan`, `build`, `revise`, `ship`, `go`,
`list`, `clean`, and `doctor` — which is new, and explains anything in the environment
that is not ready.

### Deliberate changes from the Bash implementation

- **The base branch is resolved, not assumed.** Bash meant `origin/main` in four places.
  wq now asks the repository — `origin/HEAD`, then `origin/main`, then `origin/master` —
  and records the answer in `build.env` so the branch point, every diff, and the pull
  request all agree. Repositories that never renamed their default branch now work.
- **`brainstorm`'s note directory has no default.** Bash hard-coded an iCloud Obsidian
  path. Set `WQ_VAULT` or `[paths] notes`.
- **`wq ship` passes `WQ_ROOT` into the tab it opens.** The tab is a fresh shell, so the
  invoking environment does not reach it.
- **Colour only on a TTY**, and `NO_COLOR` is honoured.
- `wq --help` is generated by Typer rather than by `sed`-ing a comment block.

`build.env`'s first four lines are unchanged, so a build started by either implementation
can be finished by the other. See [docs/parity.md](docs/parity.md).

### What the rewrite actually bought

Not fewer lines — more. What it bought is that the reliability logic is now testable:
235 tests, ~30 seconds, no herdr installation required. Every entry in
[docs/behaviors.md](docs/behaviors.md) that used to need a live agent run to verify is now
a sub-second test.
